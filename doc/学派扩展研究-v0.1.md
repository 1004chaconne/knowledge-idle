# 学派扩展研究 v0.2

> 前提：**先研究，不动手**。这份文档只回答两个问题——该做哪些学派、怎么才能做得有趣且寓教于乐。
> v0.2 变更：用户确认"全部都要做"，医学改为「救治」向、墨家补「非攻反伤」与造物召唤、新增 Unit 地基与分批依赖表。
> 判断标准不是"这个主题有名"，而是"它能不能给玩家一个现在没有的动词"。

---

## 0. 先说一个结构性发现：克制环有两段是死的

现有 8 个学派的方法论分布：

| 方法论 | 学派 | 数量 |
|---|---|---|
| 实证 | 力学、电气、光学 | 3 |
| 归纳 | 博物、热力 | 2 |
| 演绎 | 形式 | 1 |
| 诠释 | 量子、化学 | 2 |
| **先验** | — | **0** |
| **计算** | — | **0** |

克制环是六环：`实证 → 诠释 → 演绎 → 归纳 → 先验 → 计算 → 实证`。

**问题**：场上没有"先验"和"计算"的敌人，玩家就永远不需要为这两环准备书。所谓的六环克制，实际只有四环在运转——环的后半段是装饰。

**结论**：新增学派的第一优先级不是"加一个知识主题"，而是**把环补活**。补先验、补计算，比再加一个实证学派有价值得多。

## 1.5 先做地基：「己方单位（Unit）」系统

用户明确要的三件事——**医学回血、墨家造物、生物召唤**——表面是三个学派，实际上指向同一个缺失的系统。

**现状（代码事实）**：`summon` 效果目前只是一个"每 2 秒自动掉血的计时器"：

```js
B.summons.push({ id, until: 12, tick: 0, dmg, name })   // 没有血量、不可被攻击、不可被治疗
```

**这意味着**：如果不先升级地基，三个学派会各自实现一套"召唤物"，重复三遍，而且互不兼容。

### Unit 地基需要补的四件事

| 能力 | 说明 | 为什么必须有 |
|---|---|---|
| `hp / maxHp` | 召唤物有血量，会被敌人攻击 | 否则"承伤"是假的，"回血"没有对象 |
| `被治疗` | 医学的回复可以指向 Unit | 这是医学学派存在的意义 |
| `被摧毁` | 血量归零后消失，附带一次效果（爆炸/哀鸣/留下残骸） | 让"召唤"有代价，不是白嫖 DPS |
| `类型标签` | `guard`（守护/承伤）/ `strike`（输出）/ `swarm`（群体） | 三个学派各自的召唤物性格不同 |

### 为什么这是"地基"而不是"某个学派的特性"

做完这块地基，以下三件事**同时**成立：

- 医学学派有对象可治 → 「救治」动词成立
- 墨家机关能承伤、能反伤 → 「非攻」成立
- 生物召唤能繁殖、能成群 → 「种群」成立
- 反向也成立：**敌人可以打你的召唤物**，这给了敌人一个"选择"，战斗从"你打它"变成"双方都有目标"

**这一步的性价比判断**：只做地基（约 150–200 行 + 一个 UI 条），不做任何学派，玩家已经能感觉到战斗变了——因为场上第一次出现了"你的东西"。这比先做任何一个学派都划算。

## 2. 推荐先做的三个（附设计卡）


### ① 信息学派 · 图灵（补「计算」环）

**为什么是它**：放置类游戏的核心快感本来就是"看着系统自己运转"。让玩家**编排系统**，是这个品类最自然、也最缺的一层深度（Increlution 靠这个撑起整个游戏）。

- 新动词：**编排**（不是"打得更疼"，是"写一条规则让它自己打"）
- 机制：战斗中可编 1–3 条"若…则…"指令，例如
  - 若敌人抗性 > 1.2 → 换用克制学科的书
  - 若某技能 CD 好了且敌血 < 30% → 优先释放
  - 若自身血量 < 40% → 切防御书
- 为什么贴主题：图灵机就是"有限规则 + 无限纸带"。玩家的规则表就是程序，关卡就是输入。
- 反直觉点：**规则越精确，收益越高，但也越容易在意外情况下卡死**——这正是"可计算性"的边界（停机问题）。
- 书本选题：《论可计算数》《计算机器与智能》《控制论》
- Boss 三阶段：P1 判定问题（把你的技能变成"可判定/不可判定"两类）→ P2 通用机（复制你上一次的指令序列）→ P3 停机（给你 30 秒倒计时，超时即失败）
- 台词钩子：「机器能思考吗？」「这个问题本身就是答案的一部分。」

### ② 认知学派 · 康德（补「先验」环）

**为什么是它**：实现成本最低，但规则最"反直觉"，而反直觉正是这款游戏最好的味道（量子学派已经证明过一次）。

- 新动词：**预期**
- 机制：你的暴击率不是常数，而是"你相信它有多高"——
  - 连续 3 次未暴击 → 下一次暴击率 +25%（"人无法忍受随机"）
  - 连续暴击 → 暴击率回落（"回归均值"）
  - 敌人可以让你的"预期"失效（P2 阶段把面板数值显示成假的，实际按另一套算）
- 为什么贴主题：康德的核心主张是"人为自然立法"——你看到的秩序，一部分是你自带的认知结构给的。
- 教学锚点：玩家会第一次意识到"我在游戏里看到的数字，也可能被骗"。
- 书本选题：《纯粹理性批判》《作为意志和表象的世界》《格式塔心理学原理》
- Boss 三阶段：P1 先天直观（把界面上的数字打乱显示）→ P2 范畴（强制给你加一条"因果"规则：你的伤害必须延迟 1 秒结算）→ P3 物自体（显现一个无法被任何相性克制的形态，只能用纯数值磨）
- 台词钩子：「不是你看见了世界，是世界符合了你的看。」

### ③ 机巧学派 · 墨子（华夏线，传播最强）

**为什么是它**：市面上知识类游戏几乎全是西方科学史。墨家（小孔成像、杠杆、连弩、守城机械）是中文区最有辨识度的差异化内容，也是社交传播最容易被截图的一段。

- 新动词：**造物与守御**（在书桌之外多一个"工坊"位，放的是图纸不是书）
- 机制（用户已拍板的两条）：
  1. **造物/召唤**：机关是带血量的己方单位，有自己的耐久，替你承伤、按条件触发（敌人施法时射连弩打断）
  2. **非攻 · 反伤**：机关在场时，敌人对它的每次攻击都会被反弹一部分——**不是给玩家套个反伤 buff，而是"打我的东西你会疼"**。这是"非攻"最贴切的机制表达：我不攻击你，但你也攻不动我。
- 为什么贴主题：墨家是先秦唯一系统性研究"怎么造东西"的学派，《墨经》里有光学八条、力学定义——它本来就是"工程学"。而"非攻"是墨家最核心的主张，把它做成反伤而不是减伤，是机制与思想的同构。
- 教学锚点：《墨经》"景到，在午有端"就是小孔成像的描述，比西方早约两千年。
- 书本选题：《墨经》《考工记》《天工开物》
- Boss 三阶段：P1 非攻（Boss 只守不攻，你必须先破它的守）→ P2 备城门（场上出现两座器械，必须选一个拆）→ P3 兼爱（它的机关开始替你承伤——打赢要靠"理解"而不是"打穿"）
- 台词钩子：「止楚攻宋，不靠说服，靠我先算过一遍你们会怎么攻。」

**平衡红线**：反伤必须有上限（建议 ≤ 玩家最大生命 8%/秒），否则高攻 Boss 会被自己的攻击弹死，Boss 设计全部失效。

### ④ 医学学派 · 哈维（救治，不是输出）

**为什么是它**：这是唯一一个"不靠杀死敌人赢"的学派，能彻底改变书桌配置逻辑——玩家第一次需要为了"活下来"而不是"打得更疼"去配书。

- 新动词：**救治**（给自己与**己方单位**回血、延长召唤物存活）
- 机制：
  - 单体治疗：给自己回血，治疗量与已损失生命挂钩（越危险越有效）
  - 群体治疗：给场上所有己方单位回血（这是与墨家/生物召唤的耦合点）
  - **复苏**：给濒死的召唤物续命，代价是消耗自己的血量上限（哈维的血液循环：血量是流动的，不是静态的）
- 为什么贴主题：哈维的贡献不是"发现了血"，而是**证明血是循环流动的**——所以治疗不只是"加血"，而是"重新分配"。
- 教学锚点：放血疗法统治欧洲两千年，哈维用定量实验推翻了它——"测量"比"权威"可靠。
- 书本选题：《心血运动论》《论传染》《体温与代谢》
- 附带机制（原设计保留）：**诊断**——提前揭示敌人隐藏怪癖，作为医学学派的低级书功能（克机制怪）
- 台词钩子：「血不是静止的池子，它一直在绕圈。你们放了两千年的血，放的是同一个错误。」

**平衡红线（最重要的一条）**：单场战斗限时 45 秒，治疗型打法天然会"磨到超时"。所以治疗书必须**占用输出槽位**，且治疗量上限 ≈ 敌人 DPS 的 60%——**能苟，但苟不死**。否则整个后期会退化成"带两本治疗书无限挂机"。

### ⑤ 博物学派扩展 · 达尔文的"种群召唤"

用户提到"生物学可以搞点召唤技能"——这不需要新学派，**直接在现有博物学派（达尔文）里加 1–2 本召唤书**即可，成本最低。

- 与墨家的差异（这是关键，否则两个召唤体系重复）：

| | 墨家机关 | 生物种群 |
|---|---|---|
| 性格 | **硬**：耐久高、单体、可修复 | **繁殖**：初始弱，每 N 秒自我复制一只，上限后停止 |
| 强项 | 承伤、打断、反伤 | 数量压制、越打越多（滚雪球） |
| 弱点 | 怕持续伤害、怕被拆 | 怕群攻、怕"稀释"类怪癖 |
| 教学锚点 | 杠杆/连弩/小孔成像 | 马尔萨斯增长、种群上限（K 值） |

- 书本选题：《物种起源》（已有）→ 新增《人口论》（马尔萨斯）《生态位理论》
- 机制钩子：召唤物每 6 秒复制一次，数量到 5 只封顶——**"K 值"这个概念第一次被玩出来了**

## 3. 第二批（低成本、可作为"节奏补充"）

| 学派 | 一句话价值 | 复用哪个现有系统 |
|---|---|---|
| 法学·孟德斯鸠 | 每场自选一条规则，玩家自己立法 | 复用概念规则的 `B.cr` 快照机制 |

| 生态·博洛格 | 轮作：书桌换位有加成，久不换有衰减 | 复用书桌相邻加成 |

## 4. 判断"有趣"的四条检验（以后每个新学派都过一遍）

1. **新动词检验**：能不能用一句话说出玩家做的一件**新事**？如果只能说出"伤害更高""更耐打"，它是换皮。
2. **反直觉检验**：机制是否体现该学派真正的反常识主张？量子（观测改变结果）、经济（个体理性导致集体非理性）、康德（人为自然立法）都属于这类。
3. **教学锚点检验**：玩家关掉游戏后，能不能对朋友讲出一句具体的东西？不能，就是白做。
4. **耦合检验**：是否复用了现有系统（怪癖 / 概念 / 组合 / 装备 / 换书）？如果它造了一个孤岛系统，维护成本会翻倍，而且玩家感觉不到它和别的内容有关系。

## 5. 四个反模式（明确不要做）

| 反模式 | 表现 | 为什么致命 |
|---|---|---|
| 换皮学派 | 只换敌人外观、抗性和 Boss 名字，机制与力学相同 | 玩家 10 分钟就看穿，之后只为数值推进 |
| 教材感 | 把知识点做成弹窗长文，玩家顺手点掉 | 阅读不是玩法。知识必须**通过机制被体验**一次 |
| 机制过载 | 一个学派塞进三套新系统 | 每个学派只该有一个新动词，其余全部复用 |
| 环内堆叠 | 新学派继续塞进"实证" | 克制环更死，玩家的书桌配置更单调 |

## 6. 建议路线

1. **补环优先**：先做「信息·图灵（计算）」+「认知·康德（先验）」，这两环补齐后，六环克制才真正成立，现有 46 本书的克制价值也会被重新激活。
2. **差异化第二波**：华夏机巧（墨子）+ 医学（哈维），一个负责传播、一个负责让怪癖系统变好玩。
3. **节奏补充**：法学 / 地质 / 战略 三个低成本学派，可以在后期内容空档期分批上。

### 修订：用户确认「全部都要做」后的分批（v0.2）

放弃"只挑三个"，改为按**依赖关系**分批——有几个学派共用同一块地基，顺序错了要返工。

| 批次 | 内容 | 为什么在这一批 | 依赖 |
|---|---|---|---|
| **P0** | **己方单位（Unit）地基** | 医学 / 墨家 / 生物召唤 三者的共同前置 | 无 |
| **P1** | 机巧·墨子 + 博物召唤书 | 直接验证 Unit 地基；华夏线传播价值最高 | P0 |
| **P2** | 医学·哈维 | 有可治疗的 Unit 才有意义；治疗 + 召唤构成"坦克—奶"体系 | P0、P1 |
| **P3** | 信息·图灵（计算环）+ 认知·康德（先验环） | 补活克制环，不依赖 Unit | 可与 P1 并行 |
| **P4** | 法学 / 地质 / 战略 / 生态 / 天文 / 语言 / 音乐 / 经济 | 低成本补充，按反馈挑顺序 | 无 |

**两条顺序判断依据**：
- **先地基后学派**：P0 只做地基、不做学派，玩家已经能感觉到战斗变了（场上第一次出现"你的东西"），比先做任何学派都划算，还省两次返工。
- **P1 先做墨子而不是先补环**：克制环缺失是结构问题，玩家感知不到；召唤物是体感问题，立刻能感觉到。先用体感换口碑，再用补环换深度。

**判断是否值得上线的低成本实验**：先用 `?dev=1` 做"纸面原型"——只加一个新规则钩子（不写完整学派），然后跑 `autoplay.js`，看玩家的**换书行为**是否改变。如果不改变书桌配置，这个学派就还没找到它的动词。

## 附录 A：第二批（深渊 / 战斗干预）的三条硬约束

1. **战斗干预必须支持连点**：点击区用 `pointerdown` 连续触发 + 长按自动连发，不能做"每 0.5 秒只算一次"的节流；8× 倍率下输入不能被吞。
2. **收益必须有上限**：每场手动干预的额外收益设硬上限（约为自动战斗的 +15%~20%），守住"不点也能过"的放置底线。
3. **反馈必须是即时的**：每一次点击都要有可见回应（数字跳动 / 技能条缩短），否则玩家会怀疑没生效——这是手动玩法的生死线。

## 附录 B：三条平衡红线（治疗 / 反伤 / 召唤）

| 系统 | 红线 | 不守会怎样 |
|---|---|---|
| 治疗 | 治疗量 ≈ 敌人 DPS 的 60% 上限，且治疗书占用输出槽位 | 后期退化成"两本治疗书无限挂机"，45 秒限时形同虚设 |
| 反伤 | ≤ 玩家最大生命 8%/秒 | 高攻 Boss 被自己的攻击弹死，三阶段设计全废 |
| 召唤 | 召唤物总 DPS ≤ 玩家本体的 60% | 玩家无脑堆召唤，"换书配阵"这个核心玩法被绕过 |

这三条不是保守，是**保护已有的设计**——尤其是 45 秒限时，它是整个战斗系统的地基。
