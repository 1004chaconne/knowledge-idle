# 世界 BOSS「遗忘」v0.1

> 设定：理念世界由"被记住的东西"构成。遗忘不是敌人，是**所有敌人的结局**——它每周回来一次，试图把理念世界擦掉一点。

---

## 一、已经能玩的部分（单机版，无需服务端）

| 项 | 实现 |
|---|---|
| 开放条件 | 通关第一个学派（24 关）后，地图下方出现「🕳️ 遗忘 · 世界 BOSS」 |
| 刷新 | 每周一 00:00 自动重置（ISO 周号判定，跨周给一条 toast） |
| 次数 | 每周 **3 次**，赢了本周即结束（不消耗剩余次数） |
| 数值 | 以你当前关卡 BOSS 为基准 ×2.2 血 / ×1.15 攻 |
| 每周差异 | 弱点/抗性由**周号哈希**决定——同一周所有玩家面对同一套配置 |
| 机制 | 怪癖固定为「旧法失效」：同一本书用第二遍，伤害递减（遗忘的具象） |
| 三阶段 | 血量跨 66% / 33% 时「遗忘加深」：攻击 +20%，并说一句台词 |
| 胜利 | 书页 ≈ 2 倍 BOSS 掉落 + **记忆强化 +1**（永久 +1% 全局，上限 +10%） |
| 失败 | 书页 ×0.95、随机一本书等级 -1（**硬下限：不低于 1 级**） |
| 周重置 | 次数与"已击退"清空，**记忆强化永久保留** |

### 为什么惩罚要设下限

你要求"失败会减书页和书本等级"，这条设计诚实地落地了，但加了三道护栏：

1. 书页按比例扣（-5%），不是按绝对量扣——老玩家不会一次被清零
2. 每周最多掉 1 本书、1 级
3. 等级不会低于 1，品质永远不掉

理由：世界 BOSS 是**周期性**内容，玩家每周都会回来被打一次。如果一周的失败能让积累明显倒退，第二周他就不来了。**惩罚要有痛感，但不能有"前功尽弃"的绝望感。**

## 二、全服版需要什么（服务端）

当前是纯 localStorage、双击即玩。要做到"所有玩家一起打"，最少需要一个后端。最小架构：

```
表 weekly_world_boss
  week        TEXT PK      -- '2026-W44'
  hp_total    BIGINT
  hp_left     BIGINT
  cleared_at  TIMESTAMP NULL
  phase       INT          -- 1..3（服务端也能用它驱动全服事件）

表 contributions
  week        TEXT
  player_id   TEXT
  dmg         BIGINT
  updated_at  TIMESTAMP
  PRIMARY KEY (week, player_id)
```

接口只有两个：

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/world/current` | 返回本周 Boss：配置 + 剩余血量 + 我的贡献 + 我的剩余次数 |
| POST | `/world/report` | 上报本次伤害 `{dmg, duration, deckSignature}`，服务端累计 |

判定权必须在服务端：**客户端只能"上报伤害"，不能自报胜负**。

### 防作弊的现实判断

客户端存档可改，所以：

- **不要做全服排行榜**（一定被刷）
- 做**贡献度里程碑**：全服累计伤害达 25% / 50% / 75% / 100% 时，所有参与者发一次奖励。里程碑只看"总和"，个别作弊者影响有限
- 软校验：单次伤害除以战斗时长，超过该关卡理论 DPS 上限的 3 倍则标记（不封，只不计入）

### 失败惩罚在全服版里的软化

全服 Boss 可能"这一周全服都没打死"——如果还按单机版扣等级，会造成群体挫败。建议：

- 全服未击退时，**只扣书页不扣等级**（等级惩罚仅在"你自己 3 次都失败"时生效）

## 三、每周的世界事件（低成本、高氛围）

每周随 Boss 一起刷一条「理念世界的低语」，显示在世界 BOSS 面板上。文案池示例：

- 「本周，某座图书馆的第二层开始变得模糊。」
- 「有人忘了自己昨天读过的第一章。」
- 「遗忘在门口停了一会儿，然后继续走。」

**作用**：让"每周"这件事有叙事感，而不是纯数值刷新。

## 四、后续可加（按性价比）

| 项 | 说明 | 依赖 |
|---|---|---|
| **阶段奖励** | 全服伤害过 25/50/75% 各发一次书页 | 服务端 |
| **学派阵营** | 玩家选一个学派做"守护者"，该学派成员的贡献加权 | 服务端 + 账号 |
| **记忆碎片** | 失败也给少量书页（10%），避免"一周白干" | 单机版即可 |
| **遗忘的形态** | 每周 Boss 换一个"被遗忘的东西"作为外观（某本书/某个学派） | 内容 |

## 五、一句话总结

**单机版已经把"周节奏 + 一次性大考"的骨架立起来了；全服版差的只是一个共享血量池。**
先让玩家每周回来被打一次（并且记住"我能打回去"），再谈所有人一起打。
