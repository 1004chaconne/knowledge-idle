### 本地版（离线，不需要服务器）

**双击 `启动游戏.bat`**。它会用默认浏览器直接打开 `index.html`。

不需要 Python、不需要 Node、不起服务器——实测 `file://` 下 localStorage 能跨浏览器重启保留（`tools/checkfile.js` 就是干这个验证的）。

想右键 → 发送到 → 桌面快捷方式，以后从桌面点。

如果需要 http 地址（手机同局域网玩、或某些浏览器限制本地存储），用 `启动游戏-本地服务器.bat`，需要 Node.js，固定端口 8123。

## 存档为什么会"消失"（重要）

`localStorage` 按 **origin** 隔离。预览面板每次可能给你不同的端口（`127.0.0.1:57941` 之类），端口一变就是新 origin，存档自然读不到——看起来就像"每次改完代码又从零开始"。

两种解法：

1. **用固定端口起本地服务器**，以后一直打开这个地址
   ```bash
   python -m http.server 8080
   # 之后固定访问 http://localhost:8080
   ```
2. **用开发者面板的存档码**（见下），换端口/换浏览器都能把进度搬回来

## 顶栏的时间倍率（测试用）

右上角 `1× / 2× / 4× / 8×` 同时放大**产出**和**战斗推进**，倍率会存档。

战斗不是简单地把 `dt` 乘大——那样高速下技能会被吞掉（CD 跨帧只触发一次）。实际做法是每帧先算 `真实时间 × 倍率`，再用 **0.05 秒固定子步**循环结算，所以 8× 下技能释放频率与 1× 完全一致。

## 两种测节奏的方式，结论不一致时以浏览器为准

```bash
node tools/sim.js              # 逐关曲线（理想策略、纯数学）
node tools/autoplay.js 8 180   # 真实浏览器跑 180 秒，倍率 8×
```

**sim.js 实测（v0.4 当前数值，理想策略）：**

| 节点 | 游戏时间 |
|---|---|
| 第 1 轮 Boss（力学·牛顿） | 约 7:45 |
| 电气学派首 Boss | 约 42 分钟 |

## 已实现

- **8 学派 × 8 关 × 3 轮 = 192 关**，击破学派 Boss 解锁下一学派，地图可随时切回
- **难度曲线按学派重启**：每个学派有自己的 `mult` 起点，不沿用上一个学派第 3 轮的数值
- **纪元系统**：范式转移 = 进入下一纪元。敌人数值 ×2.2/纪元，学派顺序轮转重排
- **天赋树**：范式点可花在 6 个天赋上（博览 / 锐利 / 洞察相性 / 加宽书桌 / 自动升级 / 自动换书）
- **装备系统**：6 槽实体装备（笔/纸/镜/灯/袍/印），书给输出、装备给规则，范式转移后保留，含背包与图鉴
- **概念规则**：13 个可装填概念（守恒/价值/教条/可证伪…），3 个预设套组一键切换
- **人物怪癖**：精英与 Boss 带生平衍生的规则型怪癖（tick/hit/cast 三类挂点），不靠纯数值变难
- 46 本书：各学派技能书 + 属性书 + 合成独有 + 彩蛋《母猪的产后护理》
- **跨范式加成**：书桌上有多种方法论时全队技能伤害 +10%，鼓励跨学派混编
- **书桌 6 槽位**（天赋可扩到 8），同行相邻同科 +8%；槽位标注本关相性（▲ 克制 / ▼ 被抗）
- **双层相性**：学科相性 × 方法论相性（六环克制 ×1.25 / ×0.8），两者相乘
- **换书提示**：书桌底部实时提示「本关弱点 / 抗性 / 范式」以及「架上有《X》克制却没上桌」
- 品质六档，影响产出、技能倍率、等级上限；掉落品质随关卡推进 + 纪元抬高下限 + Boss 保底高一档（原典/史诗在流程内可见）
- 合成配方 7 个 + 合成失败概率掉彩蛋书
- 范式转移（转生）：清零等级与洞见，保留书与品质，书页保留一半；范式点全局加成按累计值计算
- **伤害构成条**：实时显示每本书的伤害占比，防御类书另显"生效 %"
- **卡关诊断**：失败时给 1–3 条可执行建议（相性错配 / 空槽 / 换书 / 差多少血 / 洞见没花 / 该转生了）
- **转生引导**：攒够范式点且真的卡住时弹一次说明；顶栏按钮常驻显示可得点数并呼吸提示
- 时间倍率 1×/2×/4×/8×（固定子步结算，不吞技能）
- 挂机产出、离线收益（上限 8 小时、60% 效率）、localStorage 自动存档（存档版本 v1→v3 自动迁移）
- 知识卡图鉴（击败 Boss 解锁原典摘录，lore.js 独立管理文本）
- **理念之神**：每纪元的可选终极挑战，抗性拉满、强度指数成长（×2.35/次），越打越强也给得越多
- **Boss 结算画面**：击败 Boss 弹出战报（名言 + 书页 + 掉落 + 知识卡），点"继续"才推进，9 秒自动继续
- **战斗表现**：伤害飘字（暴击更大更亮）、暴击/克制震屏、击杀粒子、血条延迟残影、技能触发时书桌槽位闪光
- **自动化开关**：书桌面板顶部常驻两个勾选项，未解锁时置灰提示去天赋里学
- **己方单位（P0 地基）**：召唤物有血量、会被敌人攻击、会被治疗、被摧毁时留下余威；三种类型（守护/攻击/群体）、场上上限 5、总 DPS ≤ 本体 60%
- **机巧学派（第 9 学派 · 墨子）**：归纳方法论，三阶段 BOSS（墨子 / 非攻 / 兼爱），精英公输班（反伤）/ 张衡（蓄势）/ 沈括（旧法失效）；6 本书，含《备城门》造守护机关、《天工开物》造输出机关
- **非攻（反伤光环）**：书桌上的《备城门》(+12%) 与《非攻》(+18%) 叠加，只要场上有己方单位，敌人打你也会被反弹，上限 30%，单次 ≤ 最大生命 8%
- **种群召唤**：《人口论》召唤会繁殖的单位，整场每 6 秒多一只，直到撞上容纳量（5 只）
- **11 个新学派（一学派一动词）**：医学·救治（给自己与单位回血）/ 认知·校验（看穿面板后 3 秒 +25%）/ 信息·编排（自动接续下一发技能 +25%）/ 法学·立判例（开局裁定攻击 +18% 或受伤 -15%）/ 经济·定价（每 8 秒花 3% 洞见买 +15% 攻击）/ 语言·命名（无视抗性）/ 天文·相位（随 8 秒周期起伏）/ 地质·沉积（层积到 12% 敌血后 1.6 倍爆发）/ 生态·轮作（每 5 秒 +3%，上限 +18%）/ 战略·先发（开场 10 秒 ×1.4）/ 音乐·和弦（双技能就绪时合奏 +45%）
- **六环补齐**：先验（认知/音乐）与计算（信息/经济/战略）两环首次有学派，克制链真正闭合
- **31 张知识卡 + 87 本书全部带史实文案**（fact / 今天在哪里 / 本课要点）
- **书籍详情随品质解锁（6 层）**：手抄本只有「简介 + 一句原文」；刊印本加「史实」；精校本加「今天在哪里」；批注本加「出处与流变 + 同源书目」；孤本加「机制解读 + 关联概念」；原典加「原典摘录」。底部固定提示「升到下一档还能读到什么」，把升阶从纯数值变成"读得更多"
- **学派条按纪元轮转顺序渲染**：学派顺序每纪元轮换，条与地图、解锁逻辑三者现在同源（旧版会出现"点音乐、地图是博物"）
- **关卡地图支持轮次切换**：`1 / 2 / 3` 三个按钮可翻阅本学派全部 24 关，不再只能看当前轮
- **实验（可重复性）**：同一关挑战到第 3 次算「数据充分」，本场伤害 +10%，并在战斗页显示该敌人怪癖的实测参数——一次成功不算证据

- **战斗干预（士气连点）**：点战斗区积士气，满 10 点让全队技能冷却 -1 秒。`pointerdown` 连续触发 + 长按自动连发（不做 0.5 秒节流），每次点击有浮动文字与日志反馈。**本场手动收益硬性封顶 = 战斗限时的 20%**（默认 9 秒），守住「不点也能过」的放置底线。

## 两个调参陷阱

1. **`STAGE_BASE_HP` 有悬崖效应**：95 → 100 曾让第 1 轮从 2:00 跳到 8:15。因为单场限时 45 秒，战力差一点就整场打不完。每次只动 5–10，改完必须复测。
2. **`sim.js` 的初始状态必须和 `defaultState()` 对齐**：漏掉初始的《落体定律》会让模拟器卡在第 4 关，看起来像平衡崩了。
